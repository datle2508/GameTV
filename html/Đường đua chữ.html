🤖 Giọng AI của Google (đọc chuẩn dấu)

Cách lấy key (miễn phí khoảng 1 triệu ký tự mỗi tháng với giọng ⭐): 1) Vào console.cloud.google.com, tạo dự án và bật thanh toán (Google yêu cầu, nhưng dùng trong hạn mức miễn phí thì không mất tiền). 2) Tìm và bật Cloud Text-to-Speech API. 3) Vào APIs & Services → Credentials → Create credentials → API key. 4) Bấm vào key → API restrictions → chỉ chọn Cloud Text-to-Speech API → Save. Dán key vào ô trên.
Chữ cần đọc được gửi tới Google để tạo giọng; mỗi từ/câu chỉ gửi một lần rồi lưu trên máy này.

🗣 Giọng của máy (dự phòng)

Nghe thử thấy sai dấu là do giọng của máy chưa tốt. Giọng có ⭐ thường đọc chuẩn hơn.
• Mac: Cài đặt hệ thống → Trợ năng → Nội dung được đọc → Giọng hệ thống → Quản lý giọng… → Tiếng Việt → tải Linh (Nâng cao) hoặc Linh (Cao cấp), rồi tải lại trang và chọn giọng đó ở trên.
• Cách dễ nhất: mở game bằng Microsoft Edge — Edge có sẵn giọng “HoaiMy (Natural)” đọc tiếng Việt rất chuẩn (cần mạng).

📚 Bài học

Micro nhận giọng nói tiếng Việt chạy tốt nhất trên Chrome hoặc Edge máy tính (cần mạng). Trên Safari cần bật Đọc chính tả của macOS. Nếu máy không có micro, bé đọc to và bố mẹ bấm “✔️ Bố mẹ chấm đúng”. Trò “Bắt bóng chữ” không cần micro, chỉ cần loa.
Nếu giọng đọc nghe như người nước ngoài: máy chưa có giọng tiếng Việt. Trên Mac vào Cài đặt hệ thống → Trợ năng → Nội dung được đọc → Giọng hệ thống → Quản lý giọng → tải giọng “Linh”. Trên Windows vào Cài đặt → Thời gian và ngôn ngữ → Giọng nói → thêm tiếng Việt.

Về đích rồi!
