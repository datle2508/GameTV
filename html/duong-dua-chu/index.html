🗣 Giọng đọc mẫu

Cách lấy key miễn phí (không cần thẻ thanh toán): 1) Vào aistudio.google.com, đăng nhập tài khoản Google. 2) Bấm Get API key → Create API key. 3) Chép key, dán vào ô trên rồi bấm Lưu key.
Gói miễn phí giới hạn số lần đọc mỗi phút và mỗi ngày. Game lưu lại âm thanh để dùng lại; khi tạm hết lượt sẽ dùng giọng của máy rồi tự thử lại sau. Với gói miễn phí, Google có thể dùng chữ gửi lên (chữ trong bài đọc) để cải thiện sản phẩm.

Cách lấy key (miễn phí khoảng 1 triệu ký tự mỗi tháng với giọng ⭐, nhưng phải bật thanh toán): 1) Vào console.cloud.google.com, tạo dự án và bật thanh toán. 2) Tìm và bật Cloud Text-to-Speech API. 3) APIs & Services → Credentials → Create credentials → API key. 4) Bấm vào key → API restrictions → chỉ chọn Cloud Text-to-Speech API → Save. Dán key vào ô trên.

Giọng có ⭐ thường đọc chuẩn hơn. Nghe sai dấu là do giọng của máy chưa tốt:
• Mac: Cài đặt hệ thống → Trợ năng → Nội dung được đọc → Giọng hệ thống → Quản lý giọng… → Tiếng Việt → tải Linh (Nâng cao), rồi tải lại trang.
• Microsoft Edge có sẵn giọng “Hoài My (Natural)” đọc khá chuẩn (cần mạng).

📚 Bài học

Micro nhận giọng nói tiếng Việt chạy tốt nhất trên Chrome hoặc Edge máy tính (cần mạng). Trên Safari cần bật Đọc chính tả của macOS. Nếu máy không có micro, bé đọc to và bố mẹ bấm “✔️ Bố mẹ chấm đúng”. Trò “Bắt bóng chữ” không cần micro, chỉ cần loa.
Nếu giọng đọc nghe như người nước ngoài: máy chưa có giọng tiếng Việt. Trên Mac vào Cài đặt hệ thống → Trợ năng → Nội dung được đọc → Giọng hệ thống → Quản lý giọng → tải giọng “Linh”. Trên Windows vào Cài đặt → Thời gian và ngôn ngữ → Giọng nói → thêm tiếng Việt.

Về đích rồi!
